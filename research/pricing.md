# Pricing and commercial licensing

**Checked:** 2026-10-15. Prices below are advertised USD before taxes, for individual use where that option is stated. Regional checkout, billing cadence, usage quotas, and AI provider charges can change the total. This is a price snapshot, not a quote.

| Environment | Current advertised entry point | What it buys and licensing point |
|---|---:|---|
| Visual Studio Code | $0 | Free for private and commercial use. Copilot and other services are separate. VS Code itself is not the same license as the MIT-licensed Code OSS source, and some remote extensions have separate terms. [License](https://code.visualstudio.com/license), [FAQ](https://code.visualstudio.com/docs/supporting/faq), [remote extension terms](https://code.visualstudio.com/preview-license). |

## Reading this table for the profile

- A no-cost editor does not mean a no-cost workflow: commercial plugin licenses, hosted model use, API tokens, and paid agent plans are separate.
- JetBrains should be costed as the actual configuration. IDEA Ultimate with its official Rust and Python plugins is one $199-first-year individual IDE subscription; buying All Products Pack may be better value if the user also wants dedicated RustRover/PyCharm instances, but those separate instances are not necessary to obtain the plugin capabilities inside IDEA.
- A subscription buys current updates/services; Sublime's personal license is a one-time payment with a defined update window. These are different cost profiles, not directly interchangeable sticker prices.
- The model's price criterion remains a broad editorial range. It does not assume a paid AI plan or estimate token volume, and should not be read as an exact total-cost-of-ownership calculation.
