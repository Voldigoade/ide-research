# Fuentes y testimonios

El registro estructurado está en [`data/sources.json`](https://github.com/Voldigoade/ide-research/blob/main/data/sources.json). Guarda identificador, título, editor, tipo, URL, fecha y clase de evidencia. La documentación del proveedor muestra soporte documentado, no demuestra privacidad o rendimiento independiente.

La auditoría usa notas y documentación oficiales de VS Code 1.142.0, IntelliJ IDEA 2026.2.3, RustRover 2026.2.4 y PyCharm 2026.2.3, VSCodium, Cursor, Zed 1.24.2, Neovim 0.12.6, Theia, Devin Desktop, Kiro, Antigravity y Tauri. Usa algunas páginas de Reddit, Hacker News y GitHub Issues como testimonios cualitativos.

Los reportes son voluntarios. Un issue demuestra que alguien describió un entorno concreto, no la frecuencia del problema ni que siga presente en la versión actual.
