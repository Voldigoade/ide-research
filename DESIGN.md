# Design system

## Purpose

Present a dense technical comparison as an evidence atlas. The visual language borrows from engineering notebooks and toolchain maps: clear labels, source trails, compact tables, and deliberate space. It does not imitate any vendor interface.

## Visual direction

- Warm paper background, graphite text, muted slate rules, and restrained teal/blue accents.
- System font stacks only. No remote fonts, images, icons, analytics, or embedded vendor content.
- Headings use a compact editorial scale. Body text remains comfortable at 16px or larger.
- Distinguish evidence labels with text and shape as well as color.
- Keep tables horizontally scrollable on small screens; preserve row labels.
- Use native links, buttons, selects, and disclosure controls.
- One signature motif: a four-layer toolchain diagram linking editor, language engine, runtime, and agent. It clarifies the comparison rather than decorating it.

## Accessibility

Target WCAG 2.2 AA as a design goal, not a certified claim. Maintain visible keyboard focus, logical headings, semantic table headers, labels for every control, reduced-motion support, and sufficient contrast. Do not communicate scores by color alone.

## Content rules

Use ranges for qualitative ratings. Label facts, corroboration, inference, and unknowns. Do not style an estimate as a measurement. Never claim that one environment is universally best.
