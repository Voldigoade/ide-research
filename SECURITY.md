# Security policy

This repository compares third-party development tools. It is not a vulnerability database and does not certify any product.

## Reporting a repository issue

For a vulnerability in this site's code or build, use GitHub's private vulnerability reporting feature if enabled. Otherwise contact the repository owner through GitHub. Do not put an unpatched exploit in a public issue.

## Product vulnerabilities

Report product vulnerabilities to the vendor's security contact. This project may link public advisories, but does not accept exploit code or secrets.

## Site behavior

The published site is static and has no first-party backend, account system, analytics, or cookies. Its comparison controls process local structured data in the visitor's browser. This describes the repository design; it is not an independent security audit.
